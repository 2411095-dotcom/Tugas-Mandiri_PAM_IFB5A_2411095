- **Nama Proyek:** ProfilInteraktif
- **Deskripsi:** Aplikasi profil mahasiswa interaktif menggunakan Jetpack Compose, State, dan Event.

### 2. Praktikum Navigasi Profil
- **Nama Proyek:** ProfilNavigasi
- **Deskripsi:** Aplikasi profil mahasiswa dengan navigasi antarhalaman menggunakan Navigation Compose dan ViewModel.

- **Nama Proyek:** CatatanKuliah
